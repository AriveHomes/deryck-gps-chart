# Deryck GPS operations dashboard

Open `index.html` to review Deryck Copley's GPS stop report from August 23 to September 23, 2026. The site is a single HTML file with embedded records and charts. The map loads Leaflet and OpenStreetMap tiles if available, and has a coordinate-plot fallback.

The four site pins use coordinates supplied by Brendan. A stop is classified as near a site when it falls within 0.25 mile of its coordinate. Other stops are clustered within 0.18 mile of a representative stop. Home-zone stops are classified from the GPS zone name. Hours sum GPS stop duration, including overnight time at home; they are not measures of work performed.

The file contains Deryck's location history and home location. Use a private repository and access-controlled hosting.
